# private/ — do not ship

Plans in this folder are derived from **modern, copyrighted** architectural
plans and are for personal in-world use only. Never bundle them with mod
releases, the planbooks library, or anything redistributed — unlike
`planbooks/` (verified pre-1930 public domain), these have no PD basis.

- `chateau-a605a` — French château, plan A605-A (contemporary plan catalog).
